banks - full list of all banks available in the app  
categories - list of names of cashback categories in every bank  
category_mcc - list of MCC codes included in every category of every bank  
excluded_mcc - list of MCC codes for each bank that never qualify for cashback, black-listed MCC  
icon_categories - icons for every bank categories (generated from icon_category_map)  
icon_category_map - directory of icons matching bank categories and merchant mcc   
mcc - full list of all mcc codes  
mcc_icon_category - icons for every merchant mcc (generated from icon_category_map)
